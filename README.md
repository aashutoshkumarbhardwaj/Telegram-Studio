# Heyaaashu Studio

AI + Tech + Career content publishing platform.

## Architecture

### apps/telegram-publisher
Telegram publishing engine based on PostingPost.

### apps/message-builder
Visual Telegram message builder based on Telegram UI Builder.

### apps/ai-content
AI research and content generation engine.

## Planned flow

Research
→ AI processing
→ Draft
→ Message Builder
→ Preview
→ Approval
→ Telegram

Later:

Telegram + X + Reddit
