# 🚀 Heyaaashu Studio — Free Cloud Deployment Guide (Render)

This guide walks through deploying Heyaaashu Studio on **Render's Free Tier** (Web Service + Managed PostgreSQL + Telegram Webhooks).

---

## 🏗️ Architecture Overview

```
                                  ┌────────────────────────┐
                                  │   Browser / Mobile     │
                                  └───────────┬────────────┘
                                              │  https://your-app.onrender.com
                                              ▼
                        ┌───────────────────────────────────────────┐
                        │        Render Free Web Service            │
                        │   • React Visual Studio (SPA Frontend)    │
                        │   • Python aiohttp REST API               │
                        │   • Telegram Webhook Receiver             │
                        └─────────────┬─────────────────────────────┘
                                      │
                                      ├───► Render PostgreSQL (Persistent DB)
                                      │
                                      └───► Telegram Bot API (Publishing & Updates)
```

---

## 📋 Step-by-Step Deployment Instructions

### 1. Push to GitHub
Ensure all code and configuration is pushed to your GitHub repository:
```bash
git add .
git commit -m "feat: prepare studio for free cloud deployment"
git push origin main
```

---

### 2. Create Render Account & Connect GitHub
1. Log in to [Render.com](https://render.com).
2. Click **New +** $\rightarrow$ **Blueprint** (or connect your GitHub repository).
3. Select your `heyaaashu-studio` repository.
4. Render will automatically detect `render.yaml` and configure:
   - **PostgreSQL Database** (`heyaaashu-postgres`, Free Tier)
   - **Web Service** (`heyaaashu-studio`, Free Tier, Docker Environment)

---

### 3. Configure Environment Variables in Render Dashboard
Under **Web Service** $\rightarrow$ **Environment Variables**, fill in your credentials:

| Variable | Description | Example |
|---|---|---|
| `DATABASE_URL` | Auto-linked from `heyaaashu-postgres` | *Managed by Render* |
| `TELEGRAM_BOT_TOKEN` | Token from [@BotFather](https://t.me/BotFather) | `123456789:ABC...` |
| `TELEGRAM_CHANNEL_ID` | Target Telegram Channel ID | `-100xxxxxxxxxx` |
| `STUDIO_AUTH_TOKEN` | Access password for Web Studio | *Auto-generated by Render* |
| `SESSION_SECRET` | Secret key for session hashing | *Auto-generated by Render* |
| `TELEGRAM_WEBHOOK_SECRET` | Secret token for Telegram Webhook security | *Auto-generated by Render* |
| `PUBLIC_APP_URL` | Your Render app URL | `https://heyaaashu-studio.onrender.com` |
| `ALLOWED_ORIGINS` | Permitted origins for CORS | `https://heyaaashu-studio.onrender.com` |
| `GEMINI_API_KEY` | *(Optional)* Google Gemini API key | `AIzaSy...` |

---

### 4. Deploy & Verify Health Check
1. Click **Apply Changes** to trigger the build.
2. Render will build the Docker container and start the web service.
3. Once deployed, verify API health:
   ```bash
   curl https://your-app.onrender.com/api/health
   ```
   **Expected Response**:
   ```json
   {
     "status": "healthy",
     "service": "heyaaashu-studio-api",
     "database": "postgresql",
     "webhook_enabled": true,
     "version": "1.0.0"
   }
   ```

---

### 5. Register Telegram Webhook
To link your Telegram Bot with the Render Webhook endpoint, run:

```bash
curl -X POST https://your-app.onrender.com/api/telegram/set-webhook \
  -H "Authorization: Bearer <YOUR_STUDIO_AUTH_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"webhook_url": "https://your-app.onrender.com/api/telegram/webhook"}'
```

**Expected Response**:
```json
{
  "success": true,
  "webhook_url": "https://your-app.onrender.com/api/telegram/webhook",
  "pending_update_count": 0
}
```

---

### 6. Test Webhook in Telegram
1. Open your Telegram bot (`@Heyaashu_bot`).
2. Send `/start` or `/daily`.
3. The bot will respond immediately through the Render Webhook!

---

### 7. Test Publishing from Visual Content Studio
1. Open `https://your-app.onrender.com` in your browser.
2. Enter your `STUDIO_AUTH_TOKEN` when prompted.
3. Create a post draft, inspect formatting, and click **Publish**.
4. Confirm post is delivered to your Telegram channel and displayed in Studio history.

---

## ⚠️ Free Tier Limitations & Operational Notes

1. **Inactivity Sleep**: Render free web services spin down after 15 minutes of inactivity. When a new request or Telegram webhook arrives, the service wakes up automatically within 20–30 seconds.
2. **PostgreSQL Expiry**: Render Free PostgreSQL databases expire after 30 days unless upgraded or backed up. For permanent production use, consider Render Starter PostgreSQL ($7/mo) or Supabase Free PostgreSQL.
3. **Webhook Security**: All webhook requests from Telegram are authenticated via the secret token header (`X-Telegram-Bot-Api-Secret-Token`). Unauthorized requests are rejected with HTTP 403 Forbidden.
